GaloreGrowth.ai Landing Page

Files:
- index.html
- styles.css
- script.js

Deploy to Cloudflare:
1. Create a new Workers & Pages project for a static site.
2. Upload these three files, or place them in a GitHub repository and connect the repository.
3. Add galoregrowth.ai as the custom domain.
4. Also add www.galoregrowth.ai and redirect one hostname to the other.

Before launch:
- Replace or connect the consultation form with your preferred lead flow.
- Add a real scheduling URL if you use Calendly, Google Calendar appointment scheduling, or another service.
- Add your privacy policy / terms if collecting leads.
- Optionally add analytics and a favicon.
